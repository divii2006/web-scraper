# Python Web Scraper

## Project Description
A beginner-friendly web scraping project using Python, Requests, and BeautifulSoup to extract webpage text and save it into a CSV file.

## Features
- Fetches webpage content.
- Parses HTML using BeautifulSoup.
- Extracts entries using `find_all()`.
- Checks the website's robots.txt rules.
- Saves extracted entries into a CSV file.
- Handles request errors.

## Technologies Used
- Python
- Requests
- BeautifulSoup4
- CSV module

## How to Run
1. Install dependencies using `pip install -r requirements.txt`.
2. Run `python scraper.py`.
3. Open `headlines.csv` to view the results.

## Output
The program successfully extracted 10 entries and saved them to `headlines.csv`.

## Learning Outcome
Learned basic web scraping, HTML parsing, and CSV file handling in Python.

Note: The current demonstration website contains quotes rather than news headlines.
